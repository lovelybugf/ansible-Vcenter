TÀI LIỆU QUY TRÌNH & BẢN THIẾT KẾ TỰ ĐỘNG HÓA KHI TRIỂN KHAI MÁY ẢO VCENTER
==============================================================================
Tệp tin này dùng để lưu trữ toàn bộ các bước từ khảo sát, thiết kế luồng, đóng gói 
EE đến cấu hình Playbook. Khi có bất kỳ thay đổi nào trong tương lai, vui lòng 
cập nhật tài liệu này trước khi chỉnh sửa mã nguồn.

------------------------------------------------------------------------------
1. KHẢO SÁT MỤC TIÊU (VMWARE / VCENTER)
------------------------------------------------------------------------------
- Môi trường hạ tầng: VMware vCenter Server API (FQDN: vcenter.amigo.lab / IP: 10.0.55.12).
- Tài khoản quản trị SSO khảo sát: soft.02@amigo.local / administrator@vsphere.local.
- Kiểm tra phiên bản vCenter/VMware:
  + Khảo sát phiên bản vCenter Server (vSphere Version 7.0 / 8.0, API REST / SOAP).
  + Xác minh độ tương thích của Ansible Collection ('vmware.vmware' hoặc 'community.vmware') 
    với phiên bản vSphere API và phiên bản Python pyVmomi trong Execution Environment.
- Các đối tượng tài nguyên: Datacenter, Clusters, ESXi Hosts, Datastores.
- Yêu cầu kỹ thuật máy ảo RHEL:
  + Tự động kiểm tra dung lượng CPU/RAM/Storage khả dụng trên Datastore.
  + Tự động kiểm tra trùng tên máy ảo trên vCenter để tránh đè dữ liệu.
  + Khởi tạo khung VM với thông số vCPU/RAM/Thin Disk tùy chỉnh.
  + Theo yêu cầu thiết kế: Để trống bước khai báo Card mạng (networks: []).
  + Gắn ISO Kickstart cài tự động hệ điều hành RHEL và bật nguồn (Power On).
  + Xác minh máy ảo bật nguồn ổn định và gửi thông báo phản hồi (Response).

3. CHỌN COLLECTION PHÙ HỢP VÀ BUILD EXECUTION ENVIRONMENT (EE)
------------------------------------------------------------------------------
- Chọn Collection: Red Hat Certified Content 'vmware.vmware' (phiên bản 2.9.0) 
  được tải từ nguồn Red Hat Console Automation Hub (redhat_hub).
- Thư viện Python bắt buộc trong EE:
  + pyVmomi>=8.0.3.0.1
  + vmware-vcenter
  + netaddr
  + pytfe>=1.2.0
- Cấu hình Build EE (Thư mục ee-build-vcenter):
  + Tệp execution-environment.yml: Định nghĩa Base Image, Python requirements, 
    Galaxy collections và các bước nạp token Red Hat Console.
  + Đóng gói thành container image và đẩy lên Quay local:
    quay-ssc2.local.amigo.com/admin/nampd-vmware-ee:v1.3

------------------------------------------------------------------------------
4. VIẾT VÀ QUẢN LÝ NGUỒN CÁC PLAYBOOK (MÔ-ĐUN HÓA AWX)
------------------------------------------------------------------------------
Tất cả các Playbook đều dùng FQCN 'vmware.vmware' và tự động nhận dạng biến môi
trường AWX Credential (VMWARE_HOST, VMWARE_USER, VMWARE_PASSWORD):

1. step1_vcenter_test_connection.yml : Kiểm tra kết nối vCenter API.
2. step2_vcenter_check_resources.yml   : Kiểm tra đủ RAM/CPU và đĩa cứng trống.
3. step3_vcenter_check_vm_name.yml     : Kiểm tra tên máy ảo chưa bị trùng.
4. step4_vcenter_select_placement.yml  : Tự chọn Datastore có dung lượng nhiều nhất.
5. step5_vcenter_create_vm.yml         : Tạo khung VM cấu hình tùy chỉnh (No NIC).
6. step6_vcenter_boot_kickstart.yml    : Gắn ISO Kickstart & bật nguồn RHEL.
7. step7_vcenter_verify_notify.yml     : Kiểm tra VM hoạt động & gửi báo cáo.
